# 陳筠婷履歷網站

這是純靜態網站，不需要安裝任何套件或建置程序。

## 發布到 GitHub Pages

1. 在 GitHub 建立新的公開儲存庫，例如 `chen-yunting-resume`。
2. 將本資料夾中的所有檔案上傳到儲存庫根目錄，包含 `index.html`、`profile.png` 與 `site-assets/`。
3. 到 GitHub 儲存庫的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. 選擇 `main` 分支與 `/(root)`，按 **Save**。
6. 等待網站部署完成；網址通常是 `https://你的帳號.github.io/chen-yunting-resume/`。

## 本機預覽

直接以瀏覽器開啟 `index.html` 即可。

## 更新內容

- 履歷內容在 `index.html`。
- 輪播與作品圖片在 `site-assets/`。
- 上傳新版檔案並推送到 `main` 後，GitHub Pages 會自動重新發布。
